# 🚀 Featured Projects

## 🔐 PRIVE SDN — Selective Disclosure Network

### Decentralized Identity Verification Platform

A privacy-preserving blockchain application designed around **selective disclosure of identity credentials**.

PRIVE SDN uses a three-role architecture consisting of **Authority, User and Validator**, with blockchain-based identity verification.

**Key features:**

* 🔑 MetaMask wallet authentication
* ⛓️ Ethereum smart contracts
* 🌳 Merkle Tree-based universal identity
* 🔐 Zero-Knowledge Proofs using zkSNARKs
* 🧾 Selective disclosure of credentials
* 🛡️ Privacy-preserving eligibility verification
* 📋 Credentials such as Aadhaar, PAN and Driving License represented through a Merkle Root

**Tech:** `React` `TypeScript` `Node.js` `Solidity` `PostgreSQL` `MetaMask` `zkSNARKs` `Merkle Trees`

## 🛡️ ReputeX — Crypto Wallet Reputation Checker

### Browser Extension for Wallet Validation

A browser extension designed to **detect and validate cryptocurrency wallet addresses across webpages**, helping users identify potentially suspicious addresses and reduce phishing risks.

ReputeX aims to provide wallet intelligence directly inside the browser by analyzing information such as:

* 👛 Wallet address validity
* 📅 Wallet age
* 📊 Blockchain activity
* 🔎 Transaction-related information
* 🛡️ Wallet reputation
* ⚠️ Potential risk indicators

**Tech:** `JavaScript` `Browser Extension APIs` `Blockchain APIs` `Wallet Analysis`

## ⚡ Fun Fact

**The first blockchain wasn't Bitcoin.**

In **1991**, Stuart Haber and W. Scott Stornetta proposed a system for securely timestamping digital documents using cryptographically linked records. Their work introduced an important early concept behind blockchain technology — creating a tamper-evident history of digital information.

Bitcoin later combined related cryptographic concepts with **proof-of-work and decentralized consensus**, turning blockchain technology into the foundation of a decentralized digital currency.
