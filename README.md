## ⚡ Fun Fact

**Bitcoin was not the first idea of a blockchain.**
Cryptographically linked records and timestamping systems existed years before Bitcoin. In 1991, researchers Stuart Haber and W. Scott Stornetta proposed a system for securely timestamping digital documents using cryptographic chains — ideas that would later become important building blocks for blockchain technology.
